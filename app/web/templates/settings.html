Not your normal Gmail password. See the steps on the right.
How to get an App Password
  1. Turn on 2-Step Verification for your Google account if it isn't already (open it).
  2. Open App passwords, type a name such as Lead Finder and click Create.
  3. Copy the 16-letter password Google shows and paste it here. Spaces don't matter.
The address and App Password are stored only on this computer, in instance/mail_settings.json, and are never shown again or uploaded anywhere. Disconnecting deletes them; you can also revoke the App Password in your Google account at any time.
Use on your phone

Open your visit route on your phone to log each visit while you walk or drive. This computer must stay on and connected.

{% if phone.ready and phone.listening %} Ready {% else %} Off {% endif %}
  1. {% if phone.ready %}{% endif %} In the .env file, set APP_PASSWORD to a password for your phone and SECRET_KEY to a long random text (not change-me).
  2. {% if phone.listening %}{% endif %} Start the app so other devices can reach it: flask run --host 0.0.0.0 --port {{ phone.port }}
  3. Connect the computer and phone to the same network. Out in the city, turn on your phone's hotspot and connect the laptop to it. If the laptop stays at home, install Tailscale on both and use the computer's Tailscale address instead.
  4. On the phone, scan the QR code or open {% if phone.url %}{{ phone.url }}{% else %}http://<this computer's IP>:{{ phone.port }}{% endif %} and sign in with the password.
The address changes when you switch networks, so check it here again. Pages on this computer never ask for the password.
